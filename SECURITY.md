# Security Policy

enowX runs coding agents and handles credentials on your machine and your servers, so we take security reports seriously.

## Reporting a vulnerability

Please **do not** open a public issue. Report vulnerabilities privately via GitHub's [private vulnerability reporting](https://github.com/enowdev/enowx/security/advisories/new).

Include steps to reproduce, the affected version, and the impact you see. We will acknowledge your report as soon as possible and keep you updated on the fix.

## Supported versions

enowX is pre-1.0. Only the latest release receives security fixes.
